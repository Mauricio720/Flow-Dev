# ADR-002: Choose the execution profile per task before Spec begins

## Status

Superseded by ADR-006

## Date

2026-10-06

## Context

The current Spec worker takes one environment-wide provider and model. The user needs different tasks to use different configured options, while retaining the existing explicit PRD, Tech Spec, and Tasks progression.

## Decision

Before the first Spec stage of each task, its author chooses a ready provider connection and an available model. The saved selection belongs to that task and governs its full Spec workflow, including retries and subsequent stages. It remains visible as non-secret metadata. A missing or unhealthy connection blocks new starts without changing approved work or existing task content.

## Alternatives Considered

### Alternative 1: One global active provider

- **Description**: An administrator changes one provider/model used by every task.
- **Pros**: Minimal selection UI.
- **Cons**: A global change could unexpectedly alter another task's execution.
- **Why rejected**: The user explicitly requires a task-level choice before the flow.

### Alternative 2: Choose anew at every stage

- **Description**: Let the author switch providers between PRD, Tech Spec, Tasks, or retries.
- **Pros**: Maximum flexibility during a task.
- **Cons**: Makes provenance and continuity harder to understand and contradicts choosing before the flow.
- **Why rejected**: The requested unit of choice is the task, not an individual stage.

## Consequences

### Positive

- Different tasks can use different ready connections without reconfiguring the worker globally.
- Reviewers can tell which option produced each Spec package.

### Negative

- A task cannot silently switch to another provider when its chosen connection becomes unavailable.

### Risks

- Existing tasks without a saved selection need an explicit pre-start choice; the product must not guess a provider.

## Implementation Notes

The TechSpec must reconcile saved task selections with worker claims, stage starts, retries, connection changes, and historical attempts.
