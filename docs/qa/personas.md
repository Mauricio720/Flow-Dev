# Personas do Flow Dev

## Marina — Power User

- `base`: Power User
- Objetivo: concluir uma Issue controlando as etapas e o modelo usado em cada uma.
- Dispositivo/rede: laptop, Wi-Fi rápido, pt-BR.
- Modalidade: teclado e mouse.
- Paciência: 30 segundos por transição sem explicação.

## Caio — Recovering User

- `base`: Recovering User
- Objetivo: retomar com segurança uma execução interrompida e confirmar o que foi ou não concluído.
- Dispositivo/rede: laptop, rede instável, pt-BR.
- Modalidade: teclado e mouse.
- Paciência: 15 segundos diante de estado ambíguo.

## Lia — Accessibility-Reliant User

- `base`: Accessibility-Reliant
- Objetivo: escolher o modo, revisar resultados e entender bloqueios usando teclado e leitor de tela.
- Dispositivo/rede: laptop, Wi-Fi rápido, pt-BR.
- Modalidade: teclado e leitor de tela.
- Paciência: 45 segundos por estado sem anúncio ou orientação.

Não há jornada móvel nativa no escopo deste ciclo; viewport estreita continua relevante como verificação responsiva.
