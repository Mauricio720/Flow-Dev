# Clarification protocol

Ask only through the Compozy clarification channel; it delivers the question to the author and waits.

- One question per request, with your recommendation stated first.
- Offer labeled options when the answers can be predetermined; allow free text only when the answer space is open.
- Skip questions the Issue, the approved inputs, the repository or earlier answers already settle, and say so in the document.
- Never answer for the author and never continue past an unanswered question that changes scope.
- Do not request broader permissions than the current stage needs. Reads are allowed; writes outside the stage paths, Git publication and network writes are not.
